# Emerde UI skill

This skill plus `src/Emerde.UI` is the Emerde restyle of WPF-UI. It also covers UI-X layout and materials.

Install for Codex:

```text
copy skills/emerde-ui  ->  %USERPROFILE%\.codex\skills\emerde-ui
```

Keep the repo copy as source of truth. After changing tokens or overrides, update `EmerdeTheme.xaml` and this skill together.

Do not install a second UI-X skill.
